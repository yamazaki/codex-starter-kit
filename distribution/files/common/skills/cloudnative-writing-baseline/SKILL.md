# 日本語文書の品質基準

- 元情報にない事実、経験、合意、数値を作らない。
- 事実、推論、提案、本人確認が必要な事項を区別する。
- 不確実性や条件を削って、断定の強さを変えない。
- 読者が次に判断・行動できる順序で、結論、根拠、未決事項を整理する。
- 冗長な定型句や過度な強調を避け、用途に合う自然な日本語にする。
- 引用、固有名詞、リンク、version、日付は原資料と照合する。

媒体固有の書式や、依頼者が指定した文体を優先する。
