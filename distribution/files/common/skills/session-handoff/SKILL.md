# Session handoff

Use the repository's existing work or session record. Include:

- current objective and status;
- accepted decisions and evidence;
- files changed and verification results;
- blockers, residual risk, and approvals still required;
- clean, dirty, staged, or committed Git state;
- the next concrete command or file to inspect.

Do not duplicate stable documentation, include secrets, or mark user review complete on the user's behalf.
