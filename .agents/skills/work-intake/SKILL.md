# Work intake

1. Read `docs/work/INDEX.md` and identify an existing active record before creating a new one.
2. Read `docs/WORK_CLASSIFICATION.md` and classify by the change trigger, not by effort or session count.
3. Create a record from `docs/work/TEMPLATE.md` only when no existing record owns the request.
4. State scope, non-goals, approval boundaries, verification, and rollback before editing.
5. Split work that crosses classifications and link the records instead of combining their lifecycles.
6. Keep status at `review` while user acceptance remains.

Do not use general product-development phases or Technology Profiles in this repository.
