# Upstream 0.78.1 command mapping

Claude Codeの21 command fileはCodexへ直接コピーしない。CodexではSkill、custom agent、native capabilityへ統合し、同じ目的を複数の入口で重複させない。機械可読な正本は `porting/command-map.json` とする。

## 方針

- workflowとdomain knowledgeはSkillへ移す。
- narrow roleはcustom agentへ移す。
- web search、review、subagentなどCodex native機能がある場合は、それを前提にする。
- external dependencyを本体へ持ち込まないcommandは理由付きDROPとする。
- custom slash command互換を前提にしない。

## 外部依存とweb処理

- `spec-kit-init`: 外部CLI、license、更新責任をstarter kitへ持ち込まないためDROPする。
- `web-article`, `web-source-review`: bundled extraction runtimeを追加せず、Codex native web searchとsource review手順へADAPTする。
