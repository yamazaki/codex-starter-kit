# Upstream 0.78.1 feature mapping

機械可読な正本は `porting/feature-map.json` とする。

## 即時ADAPT

- `agent-teams`: Claude環境flagは移植せず、Codex native subagentとPORT-0003のcustom agentsで目的を実現する。
- `auto-update`: session startで自動applyせず、保守者による本家の`sync-upstream`と、取得済みdownstream kitからの`codex-starter-kit-maintenance`によるreview・明示applyへ分離する。downstream repositoryの自動clone・pull・定期実行は提供しない。
- `pre-compact-commit`: 自動stash hookを移植せず、Codex compactionと`strategic-compact`へ統合する。
- `safety-net`: 明示opt-in、absolute command path、trust review前提のPreToolUse guardrailとして移植する。

## DROP

- `codex-plugin`: 当初要件で対象外。
- `native-file-tools`, `no-flicker`, `statusline`: Claude runtimeまたはTUI固有。
- `web-content-update`: session startでの依存自動更新はreview-first release契約と競合する。

## 初回releaseで追加しないもの

formatter/doc/PR/tmux Hook、通知、font、Ghosttyは、global設定としての侵襲性またはCodex native機能との重複が大きいため、初回releaseではDROPする。将来、具体的な利用者需要とcross-platform fixtureが揃った場合は新しいupstream判断として再評価する。

唯一配布するHookはsafety-netとする。`CODEX_HOME`を反映したabsolute command path、Codex Hook schema、event fixture、非管理Hookのtrust review、明示opt-in、install/update/uninstall/rollbackを実装・文書化した。
