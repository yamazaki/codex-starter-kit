# Upstream 0.78.1 feature mapping

機械可読な正本は `porting/feature-map.json` とする。

## Codex向けADAPT

- `agent-teams` (`platform-native-alternative`): Claude環境flagは移植せず、Codex native subagentと意味保持したcustom agentsでdelegation目的を実現する。Hook・flagの機能同等は主張しない。
- `auto-update` (`safe-operational-alternative`): session startで自動applyせず、保守者による本家の`sync-upstream`と、取得済みdownstream kitからの`codex-starter-kit-maintenance`によるreview・明示applyへ分離する。自動更新との機能同等は主張しない。
- `safety-net` (`bounded-reimplementation`): 明示opt-in、absolute command path、trust review前提のPreToolUse guardrailとして再実装する。外部`cc-safety-net`完全互換ではなく、監査済み9 command familyへ範囲を限定する。

## DROP

- `codex-plugin`: 当初要件で対象外。
- `native-file-tools`, `no-flicker`, `statusline`: Claude runtimeまたはTUI固有。
- `web-content-update`: session startでの依存自動更新はreview-first release契約と競合する。
- `pre-compact-commit`: upstreamのGit stash snapshot Hookは配布しない。Codex checkpoint・automatic compactionと`strategic-compact`は代替手段だが、data snapshotと機能同等ではない。

## 初回releaseで追加しないもの

formatter/doc/PR/tmux Hook、通知、font、Ghosttyは、global設定としての侵襲性またはCodex native機能との重複が大きいため、初回releaseではDROPする。将来、具体的な利用者需要とcross-platform fixtureが揃った場合は新しいupstream判断として再評価する。

唯一配布するHookはsafety-netとする。`CODEX_HOME`を反映したabsolute command path、Codex Hook schema、event fixture、非管理Hookのtrust review、明示opt-in、install/update/uninstall/rollbackを実装・文書化した。upstream外部runtimeとの差を隠さず、bounded reimplementationとして扱う。
