# Upstream 0.78.1 plugin dependency audit

- Upstream commit: `f8f8ef5964c83cec2a5aaf84847a85149c96f6d4`
- Source: `config/plugins.json`
- Status: reviewed for `0.78.1-codex.3` candidate

## 結論

15 Anthropic marketplace pluginsはいずれもupstream core Skills、agents、rules、通常commands、retained featuresのhard runtime dependencyではない。`config/plugins.json`はprofile別の追加plugin catalogであり、setup/uninstall、plugin adoption、pending feature通知がconsumerである。

Codex版はClaude plugin install lifecycleとfeature recommendationを配布しないため、plugin本体をDROPしてもretained workflowに欠落参照は生じない。ただしalternativeはoptionalまたはoverlapであり、plugin機能と完全同等とは主張しない。

## Dependency evidence

- 18 feature manifestsはすべて`dependencies: []`。
- upstream Skillsはplugin名をruntime requirementとして参照しない。
- agents・commandsの`code-review`参照は主に同梱agent名で、marketplace plugin API呼出しではない。
- `security-guidance`の追加処理はinstall/uninstallとlocal data cleanupに限定される。
- plugin catalogを直接読む`feature-recommendation`、upstream `update-kit` plugin adoption、Claude setup lifecycleはCodex版でDROPまたはmanifest-based maintenanceへ置換済み。

機械可読な正本は`porting/config-map.json`の`pluginAlternatives`と`pluginDependencyAudit`とする。
