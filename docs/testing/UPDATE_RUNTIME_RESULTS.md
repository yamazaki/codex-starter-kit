# 更新Hookの実起動試験

MNT-0020の未リリース実装を2026-10-11に検証した結果。既存の正式版 `.4` や本番インストールの試験結果とは区別する。

## 条件

macOS、Codex CLI `0.162.0-alpha.2`、`gpt-6.1-sol`、専用の認証領域、独立したプロジェクトとインストール先を使用した。プロジェクト内のHookから、インストール済みの `auto-update.mjs` を呼び出す。更新処理・変更計画・管理記録・バックアップは実装本体を使用し、取得処理だけを試験用のローカル取得処理に置き換えた。実GitHubの正式Release取得は別試験で確認済みであり、この試験と合わせても、更新用スクリプトを収録した正式Releaseからの一連の更新を検証済みとは扱わない。

試験専用Hookの信頼操作は本人承認を得て、公式UIのレビュー画面で実施した。確認モードから適用モードへの変更は「Modified since last trusted」と表示され、定義を再レビュー・信頼した。本番のHook、設定、インストール先は変更していない。認証情報の読み取り・コピー、信頼を迂回するオプションは使用していない。

## 結果

| 項目 | 結果 | 確認したこと |
| --- | --- | --- |
| 未信頼の起動 | PASS | Codexは応答したが、更新確認の実行記録も配布ファイルの変更もない |
| 信頼後の非同期確認 | PASS | `.3` → 試験用 `.4` の変更予定1件を通知。配布ファイルとインストール版は変更しない |
| 再信頼後の同期適用 | PASS | 試験用 `.4` → `.5` のファイル更新、構成保持、管理記録更新、復元用バックアップ作成を確認 |
| 未完了更新による停止 | PASS | 未完了記録を保持し、対象ファイルを変更しない。Codexのモデル応答がなく、入力・出力トークンはともに0 |
| 試験状態を戻した後の起動 | PASS | 今回追加した試験用未完了記録を取り除くと正常応答。余分な変更やバックアップ作成はない（間隔制限内） |

同期Hookの停止は、子プロセス試験の `continue: false` 出力と、実起動時の無変更・モデル処理なしを合わせて確認した。選択したセッション記録にはHook専用イベントが出ていないため、存在しないイベントを証拠として記載しない。CLI終了コード0や `turn.completed` だけを、モデル処理や更新の成功判定には使用していない。

初回のCLI起動は外側の実行制限による初期化エラーで中断した。許可された実行環境で再試験した。また、対話CLIの事前プロジェクト信頼指定は自動安全審査で拒否されたため、指定を外し通常の公式UIを使用した。これらの中断記録も保持し、成功結果に置き換えていない。

## 証拠と未確認事項

変更前後の管理記録・ファイル内容、CLIイベント、初期化エラー、再現用スクリプト、結果、SHA-256一覧をprivateの専用証拠領域へ保存した。認証、信頼データ、他の会話記録はコピーしていない。保存先はprivateセッション記録に記載する。

Windows/Linuxでの実起動、他の稼働中セッションとの干渉、正式Release収録版からの取得・登録、本番導入、旧installerとの更新入口統一は未確認・未完了。今回の試験でこれらを完了扱いにせず、MNT-0020は進行中を維持する。
