# 改訂版と動作検証の原記録

0.78.1-codex.4の配布準備では、.3と表記された修正済みローカルcandidateの55代表ケースの原記録を保持する。これは既存GitHub.3の配布内容そのものを検証した記録ではない。

[対応表](release-evidence-map.json)は、その受入対象と.4の配布全体・導入機構・試験定義76対象が同一であることをhashと完全な一覧で照合する。変更・欠落・追加・symlink・未reviewの対応表・不明版は拒否する。repositoryの検査でもこの対応を確認する。

原RESULTS/RUN/BATCHの版・不合格・障害は書き換えず、.4のモデル再実行数は0と明示する。版情報変更による導入・更新・復元の挙動は、.4で別に隔離検証した。全用途・全環境の保証やPublic化の承認ではない。

今後.4でモデル試験を追加する場合は、`behavior-eval.mjs prepare`で新しい版の結果を別の空フォルダへ作る。CLI BATCHの実版とRESULTSの版を一致させる。.4のBATCHを旧.3結果へimportしない。評価時には対象の原文・実操作・実子最終回答を確認し、既存の採点・証拠保全の手順を使用する。配布内容が変わった場合は、対応表を機械的に更新して済ませず、必要な新規試験を判断する。

現在の履歴結果は[結果一覧](RESULTS_SUMMARY.md)、candidateの検査と残条件は[.4の記録](../releases/0.78.1-codex.4.md)を参照する。
