## Safety boundaries

- 実applyとrollbackには明示確認が必要
- unmanaged・modified file、stale plan、symlinkはfail-closed
- auth、session、log、secretは管理対象外
- safety-netはデスクトップアプリのSettings > Hooks、またはCodex CLIの`/hooks`でreview・trustするまで実行されない
- upstream変更を自動applyしない
- downstream repositoryを自動clone・pullしない。継続配布にはpublic/private repositoryまたはrelease archive等の取得経路が必要
